# 手ぬぐい帖のデザインと改善記録

2026-10-03。目指す体験は「好きな一枚を簡単に加え、すでに集まっている自分の世界を眺め、そのまま人に見せる」です。奥さまが普段あまり並べ替えをしないことを踏まえ、展示づくりを主経路から外しました。

## 判断に使った基準

- [Webbyの公式審査基準](https://www.webbyawards.com/judging-criteria/)の視覚・ナビゲーション・機能・体験全体を参考に、写真が先に見えること、追加の入力負担、共有までの手数、操作の読みやすさを確認しました。
- [Awwwardsの公式評価例](https://www.awwwards.com/sites/str8fire)にあるDesign・Usability・Creativity・Contentを参考に、見た目と実際の使いやすさを一緒に評価しました。
- [FWAの公式解説](https://thefwa.com/FWA25/25.html)にある独創性・技術的完成度を参考に、演出の量ではなく、このコレクションに合う表現と安定した操作を重視しました。
- [Awwwards掲載のOshane Howard](https://www.awwwards.com/sites/oshane-howard)と[現在の実サイト](https://www.oshanehoward.com/)を参照しました。写真を主役にして操作を控えめにする考え方を取り入れ、手ぬぐい帖では生成り・苔色・明朝体・静かな動きで表現しています。画像や実装の転用はありません。

これは実装の判断に使った基準で、受賞判定や審査員による評価ではありません。

## 実データによる見直し

| 確認で見えたこと                                           | 改善                                                                                     |
| ---------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 大きな紹介写真と管理用の操作が、実際の一枚より先に目に入る | 紹介用ヒーローとサイドバーを外し、一覧を入口に。展示・順序変更・設定はメニューへ         |
| 商品名の店舗情報・販促語が写真より目立つ                   | 既知の商品名形式だけ表示名を短縮。原文は保持し、詳細で確認可能に                         |
| 多くのタグと検索欄が常に表示される                         | 一覧のタグは2つまで。検索・状況・並び順は必要なときに開く                                |
| 追加が記録作業に見える                                     | 写真と収集状況を主経路に。名前・タグ・思い出は任意欄へ。編集時や関連エラーでは展開       |
| 共有に展示作成が必要になる                                 | コレクション全体を直接共有。絞り込み中のURLを渡さず、ルートのリンクをコピー              |
| スマホで操作が狭い／収集状況が折り返す                     | 主要操作の44px以上、入力16px、余分な左右余白・装飾の整理、アイコン操作の読み上げ名を確認 |
| 横向きの鑑賞で写真と説明の高さが競合する                   | 低い画面では写真とキャプションを左右に分け、前後・閉じる・再生を画面内に配置             |

一覧はPC4列・タブレット3列・スマホ2列。写真をトリミングせず、最初の4枚を優先して読み込みます。鑑賞画面は一枚と短い名前を中心にし、前後移動と自動再生に対応します。動きを抑える端末設定、Escape、フォーカス復帰を維持しています。

## 確認の範囲

本番からコピーした54枚を使い、PC 1440×1000、スマホ390×844・360×740、横向き844×390で確認しました。検索「春」で13枚、収集状況で手元29枚／気になる25枚を確認。ローカルでは名前未入力・画像URL・気になるの選択だけで登録でき、検証用の一枚を復元可能な状態で棚から外して54枚へ戻しました。

コードの別担当レビューでは、検索時の再取得、共有のキャンセル・失敗、メニューと鑑賞のフォーカス、任意欄の入力保持、認証を確認しました。自動検証とCloudflare上の確認は[検証記録](verification.md)を参照してください。

実際の写真を含む今回の確認画像はローカルの`tmp/`へ保存し、Gitには追加していません。最新版は[Cloudflare Preview](https://codex-japandi-gallery-tenugui.takatama.workers.dev/)で確認できます。
